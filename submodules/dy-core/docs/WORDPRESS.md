# WordPress Core

`wp-admin/` and `wp-includes/` are WordPress Core.

- Treat WordPress Core as external dependency
- For doubts about WordPress Core functions, classes, methods, hooks, filters, parameters or return values, consult first:
    1. `https://developer.wordpress.org/?s={function|class|method|hook|filter}`
- Scans and reads in WordPress Core must be required by the current task and explicitelly approved.
