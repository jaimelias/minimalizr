# Coding

- Understand existing behavior before editing; make the smallest correct change using simple, readable, modern code.
- Prefer guards over unnecessary `try/catch`.
- Before coding, read `PHP.md` for PHP or `JS.md` for JavaScript.
- For WordPress specific topics read `WORDPRESS.md`.
- For Polylang specific topics read `POLYLANG.md`.
- After fixes or optimizations, compare original and resulting output contracts.
